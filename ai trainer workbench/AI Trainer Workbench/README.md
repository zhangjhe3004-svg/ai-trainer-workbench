# 基于 MongoDB 的电商商品与订单管理系统

NoSQL 期末大作业（方向一）配套代码，对应报告第 3、4 章。

## 目录

| 目录 | 内容 |
|---|---|
| 01_deploy | 三节点副本集配置文件、keyFile 生成、副本集初始化 |
| 02_schema | 建库、校验器、索引、RBAC 账号 |
| 03_data | 造数脚本与结果断言 |
| 04_query | 增删改查、聚合管道、索引 explain 对比 |
| 05_app | PyMongo 服务层、Flask 接口、命令行闭环演示 |
| 06_ai_training | 技能图谱学习推荐系统（AI 训练数据方向），含网页后台 + 命令行 + 完整增删改查 |

> 补充：`06_ai_training/` 是本作业的扩展方向（技能图谱学习推荐 + AI 训练库），
> 使用说明见根目录《使用文档.md》。

## 版本

- MongoDB 7.0.14（副本集 rs0，端口 27017/27018/27019）
- mongosh 2.2.6
- Python 3.10.11，PyMongo 4.6.3，Flask 3.0.3

## 说明

1. 三个节点的 host 统一写 `127.0.0.1`，不要混用 `localhost`。
2. 金额字段统一 `Decimal128`，查询条件用 `NumberDecimal` 构造，否则结果为空。
3. 支付回调以「订单号 + 待支付状态」为条件更新，重复回调返回 `duplicated=True`。
4. 造数前建议先建索引；若先灌数据，建索引期间写操作会变慢。
5. 商品列表检索按价格升序返回，与 `idx_cat_price` 复合索引对齐（ESR），避免内存排序。
6. explain 对比脚本自动选取订单量最大的活跃用户做样本，深分页与排序超限演示依赖 03_data 造数。
