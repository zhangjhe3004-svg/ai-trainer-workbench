# 命令清单（技能图谱学习推荐系统 · 按执行顺序）

> 环境：MongoDB 8.3（独立实例，127.0.0.1:27017）、mongosh 2.x、Python 3.13、PyMongo 4.x、Flask 3.x

## 1. 启动 MongoDB（若未启动）

```bash
mkdir -p ~/mongo_data
"/c/Program Files/MongoDB/Server/8.3/bin/mongod" \
  --dbpath ~/mongo_data --port 27017 --bind_ip 127.0.0.1
```

验证：`mongosh --eval "db.runCommand({ping:1})"` 返回 `{ ok: 1 }`。

## 2. 建库、建集合与索引

```bash
# 清空旧数据（可选）
mongosh --quiet --eval "db.getSiblingDB('learning').dropDatabase()"

# 业务库 learning：建集合 + 校验器 + 索引
mongosh --quiet "mongodb://127.0.0.1:27017/learning" 01_schema/create_collections.js

# 训练库 learning_ai：建集合 + 校验器 + 索引
mongosh --quiet "mongodb://127.0.0.1:27017/learning_ai" create_collections.js
```

## 3. 访问控制（启用 authorization 后执行）

```bash
mongosh --quiet "mongodb://127.0.0.1:27017/admin" 01_schema/create_users.js
```

## 4. 造数

```bash
python 02_data/generate_data.py --skills 60 --learners 200 --records 800 --assess 400
```

## 5. 查询、聚合、索引对比

```bash
# 七类增删改查
mongosh --quiet "mongodb://127.0.0.1:27017/learning" 03_query/crud.js

# 聚合管道统计
mongosh --quiet "mongodb://127.0.0.1:27017/learning" 03_query/aggregation.js

# 索引 explain() 对比
mongosh --quiet "mongodb://127.0.0.1:27017/learning" 03_query/index_explain.js
```

## 6. ETL 抽取训练样本

```bash
python etl_to_training.py --neg_ratio 4
```

## 7. 业务应用（三种入口）

```bash
# 一次性演示脚本
python demo_run.py

# 网页管理后台（浏览器访问 http://127.0.0.1:5000/）
cd app && python app.py

# 命令行交互菜单
cd app && python cli.py
```

## 8. 分片配置（分片集群，在 mongos 上执行）

```bash
mongosh --quiet "mongodb://127.0.0.1:27017/admin" shard_config.js
```
