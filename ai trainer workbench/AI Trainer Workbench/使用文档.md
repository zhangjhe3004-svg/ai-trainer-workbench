# 技能图谱学习推荐系统 · 使用文档

> 基于 MongoDB 的技能图谱学习推荐系统（NoSQL 期末大作业 · AI 训练数据方向）
> 配套目录：`06_ai_training/`

---

## 一、系统简介

本系统面向个人学习者的「技能图谱学习推荐」场景：学习者围绕一个个**技能点（Skill）**展开练习与自评，系统基于其练习行为序列与技能之间的**依赖关系（前置依赖图）**，为学习者推荐下一步最该学习的技能，实现个性化学习路径规划。

系统采用「业务库 + 训练库」双层架构：

- **业务库 `learning`**：承载在线学习服务，四个集合（skills / learners / practice_records / assessments）。
- **训练库 `learning_ai`**：承载离线 AI 训练数据，四个集合（samples / features / graph_edges / runs）。
- **ETL 层**：从业务库抽取训练样本、构建技能依赖边、抽取特征。

## 三、启动 MongoDB

系统连接的是 `127.0.0.1:27017`，需先确保 MongoDB 在该端口运行。

### 方式 A：使用独立实例（推荐，简单）

```bash
mkdir -p ~/mongo_data
"/c/Program Files/MongoDB/Server/8.3/bin/mongod" \
  --dbpath ~/mongo_data --port 27017 --bind_ip 127.0.0.1
```

> 注意：该命令会**占用当前终端窗口**（前台运行），请另开一个终端执行后续操作。

### 方式 B：使用已安装的 MongoDB 服务（Windows 服务）

若 MongoDB 已注册为 Windows 服务，直接启动服务即可：

```powershell
net start MongoDB
```

### 验证

```bash
"/c/Program Files/MongoDB/Server/8.3/bin/mongosh" --eval "db.runCommand({ping:1})"
# 输出 { ok: 1 } 即表示连接成功
```

## 四、运行系统（两种入口，任选其一）

### 入口一：网页管理后台（可视化，推荐）

```bash
cd 06_ai_training/app
python app.py
```

启动后浏览器访问：**http://127.0.0.1:5000/**

网页提供四个标签页，点按钮即可完成全部增删改查：

| 标签页 | 能力 |
|---|---|
| **技能点** | 新增技能点（含前置依赖）、查看列表、删除（级联清理） |
| **学习者** | 新增学习者、查看列表、删除（级联清理） |
| **练习记录** | 录入练习记录（自动同步训练样本）、查看列表、删除 |
| **路径推荐** | 选择学习者，生成「下一步学习」推荐 |

### 入口二：命令行交互菜单（轻量）

```bash
cd 06_ai_training/app
python cli.py
```

终端里输入数字即可操作，三级菜单导航：

```
技能图谱学习推荐系统 · 命令行管理
  1. 技能点管理     → 查看/新增/修改/删除
  2. 学习者管理     → 查看/新增/修改等级/删除
  3. 练习记录管理   → 查看/录入/删除/自评/路径推荐
  0. 退出
```

### 入口三：一次性演示脚本（跑通看效果）

```bash
cd 06_ai_training
python demo_run.py
```

该脚本自动完成「建库建索引 → 造数据 → 路径推荐 → ETL 抽取 → 查询验证」全流程，适合快速查看系统效果。

## 五、功能清单（增删改查）

### 5.1 技能点（skills）

| 操作 | 方式 | 说明 |
|---|---|---|
| 增 | 网页「新增技能点」/ 命令行 | 含前置依赖校验，依赖不存在会拦截 |
| 删 | 网页删除按钮 / 命令行 | **级联**清理依赖边 + 特征 |
| 改 | 命令行「修改技能点」 | 改难度、改前置依赖（自动重建依赖边） |
| 查 | 网页列表 / 命令行 | 支持关键字、领域筛选、分页 |

### 5.2 学习者（learners）

| 操作 | 方式 | 说明 |
|---|---|---|
| 增 | 网页「新增学习者」/ 命令行 | 含等级、学习年限 |
| 删 | 网页删除按钮 / 命令行 | **级联**清理练习、自评、训练样本 |
| 改 | 命令行「修改等级」/ REST 接口 | 改等级、年限、标签 |
| 查 | 网页列表 / 命令行 | 支持关键字、等级筛选 |

### 5.3 练习记录（practice_records）

| 操作 | 方式 | 说明 |
|---|---|---|
| 增 | 网页「录入练习记录」/ 命令行 | 选择学习者 + 技能 + 对错，**自动同步训练样本** |
| 删 | 网页删除按钮 / 命令行 | |
| 改 | REST 接口 `PUT /api/records/<id>` | 改状态、得分 |
| 查 | 网页列表 / 命令行 | |

### 5.4 附加功能

- **路径推荐**：基于技能依赖图，推荐「前置已满足且未学」的技能。
- **自评录入**：录入掌握度评分（1~5），作为显式反馈同步到训练样本的 `mastery` 字段。
- **ETL 抽取**：练习记录自动展开为「学习者 × 技能点」训练样本，`uniq_learner_skill` 唯一索引保证幂等去重。

## 六、REST 接口参考

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/skills` | 技能点列表（支持 keyword/domain/page/size） |
| POST | `/api/skills` | 新增技能点 |
| GET | `/api/skills/<id>` | 技能点详情 |
| PUT | `/api/skills/<id>` | 修改技能点 |
| DELETE | `/api/skills/<id>` | 删除技能点 |
| GET | `/api/learners` | 学习者列表 |
| POST | `/api/learners` | 新增学习者 |
| PUT | `/api/learners/<id>` | 修改学习者 |
| DELETE | `/api/learners/<id>` | 删除学习者 |
| GET | `/api/records` | 练习记录列表 |
| POST | `/api/records` | 录入练习记录 |
| PUT | `/api/records/<id>` | 修改练习记录 |
| DELETE | `/api/records/<id>` | 删除练习记录 |
| POST | `/api/assessments` | 新增自评 |
| GET | `/api/recommend/<learner_id>` | 路径推荐 |

请求示例（新增技能点）：

```bash
curl -X POST http://127.0.0.1:5000/api/skills \
  -H "Content-Type: application/json" \
  -d '{"title":"机器学习","domain":"编程","sub_domain":"Python","difficulty":0.9,"prerequisites":["数据分析"]}'
```

## 八、数据模型速查

### 业务库 `learning`

| 集合 | 关键字段 | 说明 |
|---|---|---|
| skills | code / title / domain / difficulty / prerequisites | 技能点，含前置依赖 |
| learners | nickname / level / years / tags | 学习者 |
| practice_records | learner_id / skills[] / score / status | 练习记录，明细内嵌 |
| assessments | learner_id / skill_id / rating / content | 掌握度自评 |

### 训练库 `learning_ai`

| 集合 | 关键字段 | 说明 |
|---|---|---|
| samples | learner_id / skill_id / label / mastery | 训练样本（正/负） |
| features | entity_type / entity_id / difficulty | 特征与画像 |
| graph_edges | from_skill / to_skill / rel_type | 技能依赖边 |
| runs | run_id / model / split / metrics | 实验元数据 |

### 关键索引

| 集合 | 索引 | 用途 |
|---|---|---|
| samples | `{learner_id, skill_id}` 唯一 | 样本去重（幂等抽取） |
| samples | `{learner_id, created_at}` | 按学习者取序列 |
| practice_records | `{learner_id, finished_at}` | 练习序列查询 |
| graph_edges | `{from_skill, to_skill}` 唯一 | 依赖边去重 |

## 九、常见问题

**Q1：运行报 `MongoNetworkError`？**
MongoDB 未启动。请先按第三节启动 MongoDB。

**Q2：网页能打开但数据为空？**
首次使用需先新增技能点和学习者。可先跑 `python demo_run.py` 初始化一批演示数据，或直接在网页里逐个新增。

**Q3：新增技能点报「前置技能不存在」？**
前置依赖是强校验的。请先创建前置技能，或把「前置技能」留空。

**Q4：路径推荐为空？**
说明该学习者已掌握所有技能，或其未学技能的前置条件都未满足。可先通过练习记录让学习者掌握更多技能。

**Q5：想清理全部数据重新开始？**
```bash
mongosh --eval "db.getSiblingDB('learning').dropDatabase(); db.getSiblingDB('learning_ai').dropDatabase()"
```
然后重启应用（重启时会自动重建索引）。
