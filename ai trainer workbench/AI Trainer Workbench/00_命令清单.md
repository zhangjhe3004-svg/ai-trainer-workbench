# 命令清单（按执行顺序）

> 环境：MongoDB 7.0.14 副本集（27017/27018/27019）、mongosh 2.2.6、Python 3.10.11、PyMongo 4.6.3

## 1. 部署与初始化
```bash
bash 01_deploy/gen_keyfile.sh
mongod --config 01_deploy/mongod_27017.conf --fork
mongod --config 01_deploy/mongod_27018.conf --fork
mongod --config 01_deploy/mongod_27019.conf --fork
mongosh --port 27017 01_deploy/init_repl.js
```

## 2. 建集合、索引与账号
```bash
mongosh "mongodb://127.0.0.1:27017/admin" 02_schema/create_users.js
mongosh "mongodb://shopApp:App%402026@127.0.0.1:27017/shop?authSource=shop" 02_schema/create_collections.js
```

## 3. 造数与断言
```bash
python 03_data/generate_data.py --products 120000 --users 50000 --orders 300000 --reviews 120000
mongosh "mongodb://shopApp:App%402026@127.0.0.1:27017/shop?authSource=shop" 03_data/assert_queries.js
```

## 4. 查询、聚合、索引对比
```bash
mongosh "mongodb://shopApp:App%402026@127.0.0.1:27017/shop?authSource=shop" 04_query/crud.js
mongosh "mongodb://shopApp:App%402026@127.0.0.1:27017/shop?authSource=shop" 04_query/aggregation.js
mongosh "mongodb://shopApp:App%402026@127.0.0.1:27017/shop?authSource=shop" 04_query/index_explain.js
```

## 5. 业务应用
```bash
cd 05_app
pip install -r requirements.txt
python demo.py          # 命令行完整闭环
python app.py           # Flask 接口，http://127.0.0.1:5000
```

## 6. 备份与恢复
```bash
mongodump --uri="mongodb://shopAdmin:Admin%402026@127.0.0.1:27017/?authSource=admin" --db=shop --gzip --out=/backup/20261106
mongorestore --uri="mongodb://shopAdmin:Admin%402026@127.0.0.1:27017/?authSource=admin" --gzip /backup/20261106
```

## 7. 故障接管验证
```bash
mongosh "mongodb://shopAdmin:Admin%402026@127.0.0.1:27017/?authSource=admin" \
  --eval 'rs.stepDown(60)'
# 观察新主节点选举，应用侧写入自动恢复
```
